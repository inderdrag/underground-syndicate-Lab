# 🧪 UNDERGROUND SYNDICATE: LAB & BOTANY SIMULATOR

> **Автономный симулятор подпольной лаборатории и ботаники:** Каннабис, Псилоцибиновая микология, Хим-синтез ЛСД-25, Порошковый цех «Аврора», Фабрика фармы PHARMA (22 препарата), сбыт, теневой рынок и дегустационная лаборатория с GL-шейдерами.

---

## ⚡ СКАЧАТЬ ИГРУ (.EXE ДЛЯ WINDOWS)

Вам **не нужно** устанавливать Node.js, компилировать код или настраивать среду. Готовые файлы собираются автоматически на серверах GitHub:

1. Перейдите во вкладку **[Releases](../../releases)** в вашем репозитории.
2. В блоке **Latest Release** скачайте подходящий файл:
   * 📦 **`Underground-Syndicate-Setup.exe`** — полноценный установщик (создаёт ярлык на рабочем столе и в меню «Пуск»);
   * 🚀 **`Underground-Syndicate-Portable.exe`** — портативная версия в одном `.exe` (запуск в один клик без установки).
3. Запустите скачанный файл и играйте!

---

### 🛡️ Предупреждение Windows SmartScreen
При первом запуске Windows может показать синее окно: **«Windows защитила ваш компьютер»** *(это стандартная реакция на новые инди-игры без платного цифрового сертификата)*:
1. Нажмите **«Подробнее»** (*More info*).
2. Нажмите **«Выполнить в любом случае»** (*Run anyway*).

## 🌐 ВАРИАНТ БЕЗ УСТАНОВКИ (ОФЛАЙН В БРАУЗЕРЕ)

Если вы хотите запустить игру прямо в браузере без установки:
* Скачайте файл **`Underground-Syndicate-Game.html`** из корня репозитория или из раздела **Releases**.
* Дважды кликните по нему — игра мгновенно откроется в любом браузере и будет работать **на 100% офлайн** без интернета с сохранением прогресса.

## 🤖 КАК РАБОТАЕТ АВТОСБОРКА НА GITHUB ACTIONS

В проекте настроен автоматический облачный пайплайн (`.github/workflows/build-windows.yml`):
* При каждом `git push` в ветку `main` сервер GitHub самостоятельно:
  1. Разворачивает чистую Windows-машину;
  2. Устанавливает все зависимости и собирает проект;
  3. Упаковывает `.exe` (Installer и Portable) через Electron Builder;
  4. Автоматически публикует готовые файлы в раздел **Releases** с новым номером версии.

## 📱 АДАПТИВНОСТЬ ПОД ТЕЛЕФОНЫ И ПЛАНШЕТЫ

* **Управление одной рукой**: Нижняя навигационная панель с удобными шторками (*Bottom Sheets*) для быстрого доступа ко всем 14 цехам и лабораториям.
* **Объединённое меню опций**: В шапке расположена компактная кнопка, объединяющая **Дегустационную лабораторию (16 веществ)**, смену языка (**RU / EN**), шрифты (**Inter, Golos, Unbounded**) и переключатель звука.
* **Интерактивные мини-игры**: Синтез в реакторах, титрование, пресс таблеток и контроль полива оптимизированы под сенсорные экраны.

## 🔬 ОСНОВНЫЕ ЦЕХА И ВОЗМОЖНОСТИ

* 🌿 **Ботаника (Каннабис)**: DWC-гидропоника, кокосовый субстрат, удобрения, полив, топпинг и пролечка шишек.
* 🍄 **Микология «Астрал»**: Монотубы, пастеризация зерна, контроль влажности/CO2 и сбор псило-грибов.
* 🧪 **Синтез ЛСД-25**: 5-этапный органический синтез, контроль температуры, фильтрация и пропитка блоттеров.
* 📦 **Порошковый цех «Аврора»**: Роторный помол 2800 RPM, гидравлический пресс 72 Bar, грейд S+.
* 💊 **Фармацевтика PHARMA (22 препарата)**: Синтез в реакторах с физикой вязкости, титрование, бланки рецептов (107-1/у, 148-1/у, спецбланки) и аптечная витрина.
* 🛒 **Теневой рынок & Darknet**: Оптовые поставки сырья, оборудования и отмыв XMR.
* ✨ **Дегустационная лаборатория**: 16 психоактивных эффектов с шейдерами реального времени.

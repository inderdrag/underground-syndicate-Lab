# 🧪 UNDERGROUND SYNDICATE: LAB & BOTANY SIMULATOR

> Полнофункциональный симулятор подпольного синдиката: ботаника (каннабис), псилоцибиновая микология «Астрал», 5-этапный хим-синтез ЛСД-25, порошковый цех «Аврора», фабрика фармы PHARMA (22 препарата), сбыт, курьерские подработки, темный рынок и дегустационная лаборатория с GL-шейдерами.

## 🚀 АВТОСБОРКА .EXE НА СЕРВЕРАХ GITHUB (БЕЗ NODE.JS НА ВАШЕМ ПК)

В репозиторий добавлен файл **`.github/workflows/build-windows.yml`**.  
Это инструкция для GitHub: **«При каждом пуше в main — автоматически собери .exe на серверах GitHub и выложи готовый установщик в Releases»**.

Вам **не нужно** ставить Node.js, компилировать код или держать открытой консоль на своём компьютере.

---

### 📋 Что сделать в GitHub Desktop:

1. Скопируйте файлы в вашу локальную папку репозитория:
   * Папку **`.github/`** (содержит рабочий процесс автосборки);
   * Обновленный **`README.md`**;
   * Остальные файлы проекта.
2. Откройте **GitHub Desktop** — во вкладке **Changes** отобразятся изменения.
3. Внизу впишите сообщение коммита (например: `Автосборка exe и обновление`) и нажмите **Commit to main**.
4. Сверху нажмите синюю кнопку **Push origin** (или Publish).
5. Перейдите на страницу вашего репозитория на GitHub в браузере → откройте вкладку **Actions**:
   * Вы увидите запущенный процесс `Build Windows EXE Release` (сборка занимает 3–5 минут).
6. Когда сборка завершится зеленой галочкой — перейдите во вкладку **Releases**:
   * Там будут ждать готовые файлы:
     * 📦 **`Underground-Syndicate-Setup.exe`** — полноценный инсталлятор (создает ярлык на рабочем столе и в «Пуске»);
     * 🚀 **`Underground-Syndicate-Portable.exe`** — портативная версия в одном файле (запуск без установки);
     * 🌐 **`Underground-Syndicate-Game.html`** — автономный офлайн-файл для любого браузера.
7. Ссылку на страницу **Releases** можно сразу отправлять игрокам!

## 📱 ПОЛНАЯ АДАПТАЦИЯ ПОД СМАРТФОНЫ И ПЛАНШЕТЫ

Интерфейс оптимизирован для мобильных устройств (iOS / Android):
* **Управление одной рукой (Thumb-Zone)**: Снизу закреплена удобная 5-кнопочная панель с выезжающими шторками (*Bottom Sheets*) для быстрого выбора всех 14 лабораторий и цехов.
* **Safe Area & Viewport**: Корректные отступы под вырезы экранов (Dynamic Island, «челки», скругленные углы) без случайного зума.
* **Объединенное меню опций**: В шапке расположена компактная кнопка, объединяющая **Дегустационную лабораторию (16 веществ)**, смену языка (**🇷🇺 RU / 🇬🇧 EN**), выбор шрифтов (**Inter, Golos, Unbounded, Системный**) и переключатель звуков.
* **Адаптивные мини-игры**: Все интерактивные элементы (удержание подогрева реактора, раскрутка миксера, титрование, пресс таблеток, расслоение фаз) оптимизированы под сенсорные экраны.

## 🔬 ЦЕХА И ВОЗМОЖНОСТИ СИНДИКАТА

1. **🌿 Ботаника & Гроушоп (Каннабис)**:
   * Быстрый цикл роста (15 часов), гидропоника DWC, кокос, органика, полив, обрезка и пролечка.
   * Синхронизация лицензий гровера с Мегамаркетом.

2. **🍄 Микология «Астрал» (Псило-грибы)**:
   * Монотубы, стерилизация зерна, контроль влажности/CO2 и споровые сертификаты.

3. **🧪 Хим-синтез ЛСД-25**:
   * 5-этапная рефлюксная реакция, фильтрация, осаждение и дозирование на блоттеры.

4. **📦 Порошковый цех «Аврора»**:
   * Роторный помол 2800 RPM, прессовка 72 Bar и грейд S+.

5. **💊 Фабрика & Аптека PHARMA (22 препарата)**:
   * Синтез в реакторах: удержание температуры и оборотов миксера с физикой вязкостного сопротивления.
   * Титрование растворов и штамповка блистеров.
   * Рецептурные бланки 107-1/у, 148-1/у-88, спецбланки 107/у-НП и витрина аптеки.

6. **🛒 Теневой Мегамаркет & Darknet**:
   * Оптовая закупка баз, катализаторов, солнечных панелей 400W и фильтров.

7. **🏃 Курьер & Закладки**:
   * 4 района города, риски облав полиции и быстрая наличка.

8. **✨ Дегустационная лаборатория (Sample FX)**:
   * 16 психоактивных эффектов с кастомными GL-шейдерами в реальном времени.

9. **📖 База знаний (Справочник)**:
   * Подробные инструкции к каждому разделу, формулы и таблица отмыва криптовалюты.

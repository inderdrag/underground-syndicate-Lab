# 🧪 UNDERGROUND SYNDICATE: SIMULATOR & LAB

> Полный автономный симулятор подпольного синдиката, ботаники, микологии, хим-синтеза ЛСД-25, порошкового цеха, фармацевтической фабрики (22 препарата), сбыта и теневой экономики.

---

## 🎮 КАК ЗАПУСТИТЬ ИГРУ В 1 КЛИК (БЕЗ УСТАНОВКИ И БЕЗ ПАПОК)

### 🚀 Вариант 1: Запуск одного файла (Самый быстрый, без программ)
Вам **не нужны** Node.js, терминал, консоли или сторонние папки.
1. Скачайте файл **`Underground-Syndicate-Game.html`** (или `Play-Game-Offline.html`) из репозитория / релизов.
2. Дважды кликните по скачанному файлу.
3. Игра мгновенно откроется и работает **полностью офлайн** с полной функциональностью, сохранениями, звуковыми эффектами, физикой реакторов и шейдерами!

---

### 💻 Вариант 2: Готовый установочный файл Windows `.exe` (Инсталлятор)
На странице **Releases** на GitHub собраны готовые установочные пакеты:
* 📦 **`Underground-Syndicate-Setup.exe`** — полноценный Windows-инсталлятор (создает ярлык на рабочем столе и в меню «Пуск»).
* 🚀 **`Underground-Syndicate-Portable.exe`** — портативная версия в одном `.exe` (работает сразу без установки).

---

### ⚡ Вариант 3: Быстрый запуск на Windows через скрипт
Если вы скачали ZIP-архив репозитория:
* Запустите **`Play-Game-Windows.bat`** — игра откроется автоматически.
* Запустите **`Install-Desktop-Shortcut.bat`** — создаст удобный ярлык игры на вашем рабочем столе.

## 🔬 ОСНОВНЫЕ ВОЗМОЖНОСТИ И ЦЕХА СИНДИКАТА

1. **🌿 Ботаника & Гроушоп (Каннабис)**:
   * Быстрый и сбалансированный цикл роста (15 часов), 3 среды (Земля, Кокос, DWC-Гидропоника).
   * Лицензирование семян, полив, обрезка, дефолиация и пролечка.

2. **🍄 Микология «Астрал» (Псило-грибы)**:
   * Монотубы, стерилизация зерна, контроль влажности/CO2 и сбор урожая.
   * Синхронизация споровых сертификатов с Мегамаркетом.

3. **🧪 Хим-синтез ЛСД-25**:
   * 5-этапная рефлюксная реакция, хроматография и дозирование на блоттеры.

4. **📦 Порошковый цех «Аврора»**:
   * Очистка кристаллов, роторный помол 2800 RPM, прессовка 72 Bar и грейд S+.

5. **💊 Лаборатория & Аптека PHARMA (22 препарата)**:
   * Реакторы нагрева и миксеры с физикой вязкостного затухания.
   * Титрование катализаторов и штамповка таблеток.
   * Бланки рецептов 107-1/у, 148-1/у-88 и 107/у-НП, витрина аптеки и проверка подделок.

6. **🛒 Теневой Мегамаркет & Darknet**:
   * Оптовые закупки сырья, оборудования и лицензий.

7. **🏃 Подработки & Курьер**:
   * Закладки в 4 районах города, риски патрулей и быстрый заработок.

8. **✨ Дегустационная лаборатория (Sample FX)**:
   * 16 психоактивных эффектов с кастомными GL-шейдерами в реальном времени.

9. **📖 База знаний (Handbook)**:
   * Полные формулы, инструкции к каждому цеху и экономика отмыва крипты.

## 🛠️ Сборка для разработчиков

```bash
# Установка зависимостей
npm install --legacy-peer-deps

# Запуск локального сервера разработки
npm run dev

# Сборка автономного файла HTML
npm run build

# Сборка .exe инсталлятора для Windows
npm run dist:win
```

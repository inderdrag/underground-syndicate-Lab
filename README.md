Интерактивный симулятор культивации ботаники, микологии псилоцибина, органо-синтеза ЛСД-25 и кокаина, фармацевтической аптеки «Авиценна» и теневой экономики.

Оптимизирован для игры как на **ПК**, так и на **Смартфонах (iOS / Android)** с адаптированной нижней панелью навигации.

## 💻 1. КАК ИГРАТЬ НА ПК (WINDOWS / MACOS / LINUX)

Гра в один клик **без установки Node.js, без консолей и без дополнительного ПО**:

### ⬇️ Быстрый запуск в 1 клик:
1. На странице GitHub нажмите кнопку **`< Code >`** ➔ **`Download ZIP`**.
2. Распакуйте скачанный ZIP-архив в любую папку на диске.
3. Внутри папки запустите файл:
   👉 **`Underground-Syndicate-Launcher.html`** (или **`Play-Game-Offline.html`**)
4. Игра мгновенно откроется в вашем браузере (Chrome / Edge / Yandex / Firefox / Opera) со всей графикой, реактором и звуковыми эффектами!

### 🖥️ Сборка нативного .exe приложения (для Windows):
Если вы хотите получить классический установочный файл **`Underground Syndicate Setup.exe`**:
```cmd
npm run dist:win
```
Готовый установочный файл появится в созданной папке `dist-electron`.

## 📱 2. КАК ИГРАТЬ НА СМАРТФОНЕИ (IOS / ANDROID)

Игра полностью адаптирована под экраны телефонов с нижним меню навигации (**Bottom Tab Navigation**).

### 🍏 Инструкция для iPhone & iPad (iOS - Safari):
1. Передайте файл `Underground-Syndicate-Launcher.html` на телефон (через AirDrop, Telegram, iCloud) или откройте прямую веб-ссылку в **Safari**.
2. Внизу Safari нажмите кнопку **«Поделиться»** (иконка квадрата со стрелкой вверх 📤).
3. Пролистайте меню вниз и выберите **«На экран "Домой"»** (Add to Home Screen).
4. Нажмите **«Добавить»** в правом верхнем углу.
5. На рабочем столе появится иконка приложения **Underground Syndicate**. Теперь игра запускается на весь экран как полнофункциональное мобильное приложение!

### 🤖 Инструкция для Android (Chrome / Yandex / Edge / Opera):
1. Откройте файл `Underground-Syndicate-Launcher.html` или веб-ссылку в браузере **Google Chrome** (или Yandex/Edge).
2. Нажмите на три точки **«⋮»** в правом верхнем углу браузера.
3. Выберите пункт **«Установить приложение»** или **«Добавить на главный экран»**.
4. Подтвердите установку. Иконка появится на вашем рабочем столе для мгновенного запуска offline!

## ⚡ СКАЧАТЬ ИГРУ ДЛЯ WINDOWS (.EXE)

Вам **не нужно** устанавливать Node.js, компилировать код или настраивать окружение. Готовые исполняемые файлы собираются автоматически на серверах GitHub:

1. Перейдите во вкладку **[Releases](../../releases)** на странице этого репозитория.
2. В блоке **Latest Release** скачайте подходящий файл:
   * 📦 **`Underground-Syndicate-Setup.exe`** — полноценный инсталлятор (создаёт ярлык на рабочем столе и в меню «Пуск»);
   * 🚀 **`Underground-Syndicate-Portable.exe`** — портативная версия в одном `.exe` (запуск в один клик без установки).
3. Запустите файл и играйте!

## 📱 ОНЛАЙН В БРАУЗЕРЕ И УСТАНОВКА НА ТЕЛЕФОН (PWA)

Игра доступна онлайн по прямой ссылке:

Игру можно установить на смартфон прямо из браузера как полноценное приложение:

  1. Перейдите по ссылке [https://underground-syndicate-lab-botany-simulator.ai.studio](https://underground-syndicate-lab-botany-simulator.ai.studio) в мобильном браузере.

  1. Откройте ссылку [https://underground-syndicate-lab-botany-simulator.ai.studio](https://underground-syndicate-lab-botany-simulator.ai.studio) в браузере Safari.
  2. Нажмите кнопку **«Поделиться»** (квадрат со стрелкой вверх внизу экрана).
  3. Прокрутите список и нажмите **«На экран «Домой»»** (Add to Home Screen).

## 🤖 АВТОМАТИЧЕСКАЯ ОБЛАЧНАЯ СБОРКА НА GITHUB ACTIONS

В проекте настроен автоматический рабочий процесс (`.github/workflows/build-windows.yml`):
* При каждом `git push` в ветку `main` GitHub автоматически:
  1. Разворачивает виртуальную машину Windows;
  2. Устанавливает зависимости и выполняет сборку;
  3. Упаковывает `.exe` (Installer и Portable) через Electron Builder;
  4. Автоматически публикует готовые файлы в раздел **Releases** с новым номером версии.

## 🔬 ЦЕХА И ВОЗМОЖНОСТИ

* 🌿 **Ботаника (Каннабис)**: DWC-гидропоника, кокосовый субстрат, удобрения, полив, топпинг и пролечка шишек.

* 🧪 **Синтез ЛСД-25**: 5-этапный органический синтез, контроль температуры, фильтрация и пропитка блоттеров.
* 📦 **Порошковый цех «Аврора»**: Роторный помол 2800 RPM, гидравлический пресс 72 Bar, грейд S+.
* 💊 **Фармацевтика PHARMA (22 препарата)**: Синтез в реакторах с физикой вязкости, титрование, бланки рецептов (107-1/у, 148-1/у, спецбланки) и аптечная витрина.
* 🛒 **Теневой рынок & Darknet**: Оптовые поставки сырья, оборудования и отмыв XMR.
* ✨ **Дегустационная лаборатория**: 16 психоактивных эффектов с шейдерами реального времени.
